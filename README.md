# MD JEWELERS - Gold Loan Settlement & Gold Buying Platform

A high-converting, professional, mobile-first fintech web application for **MD JEWELERS**, specializing in releasing pledged gold from Muthoot Finance, Manappuram, and nationalized banks with ₹0 advance fees.

## Key Features

- **₹0 Advance Fee Gold Release**: Clear gold loans across Muthoot, Manappuram, and banks with spot counter settlement.
- **Smart Settlement & Valuation Estimator**: Interactive calculator supporting:
  - Cash Settlement (Full loan takeover & balance payout)
  - Partial Release (Sell a portion of gold, retain essential jewellery)
  - Sell Old Physical Gold (Instant spot cash)
- **Live Gold Market Ticker**: Real-time 24K and 22K per gram market rates.
- **Mobile-First Responsive Design**: Optimized down to 320px screen widths with zero horizontal blowout.
- **Instant WhatsApp & Phone Lead Capture**: Direct integration for fast customer quotes and valuation.
- **Fintech UI/UX**: Google Pay & PhonePe inspired color palette, micro-guarantees, and trust badges.

## Tech Stack

- **Framework**: React 18 + TypeScript
- **Bundler**: Vite 7
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
